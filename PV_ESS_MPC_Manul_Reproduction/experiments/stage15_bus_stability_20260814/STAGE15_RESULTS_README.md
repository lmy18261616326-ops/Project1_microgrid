## 已确认的根因

1. **电池功率前馈符号错误**  
   `Pnet = Ppv - Pdc - Pac`。模型约定电池电流正值为放电，因此功率不足时 `Pnet < 0` 应产生正放电指令。原求和为“外环 PI + I_forward”，实际会在功率不足时命令充电。副本中改为“外环 PI - I_forward”。

2. **电池电感与电流内环不适合大信号负载阶跃**  
   原 `Lbat = 11.25 mH` 使电池电流反向过慢；原电流 PI 在很小电流误差下即触发占空比限幅，呈继电器式切换。最终采用：

   - `Lbat = 0.5 mH`
   - `Kpi_bat = 5e-3`
   - `Kii_bat = 0.05`

3. **交流阶跃负载 C 相接线错误**  
   阶跃断路器的 B、C 相曾接到同一物理网络，导致投入后明显三相不平衡。副本中 C 相已重新接到母线 C 相。修复后的 0.6 s 回归三相不平衡度为 0.171%。

4. **From Workspace 最终值外推错误**  
   两个直流负载电阻和电网标幺电压使用微小时间间隔形成阶跃；设置为 `Extrapolation` 后会继续沿斜率外推，产生负电阻或巨大负标幺电压。相关块均改为 `Holding final value`。

5. **完整场景交流负载基值与论文事件表不一致**  
   论文在 0.5 s 投入总计 0.5 MW 的交流负载，并在 1.0 s 加入 0.6 MW 直流负载，因此当时总负载应约 1.1 MW。完整场景使用近似开路的 1 W 基础交流负载，再在 0.5 s 投入 0.5 MW；独立回归脚本则覆盖为 0.5→1.0 MW。

6. **低负载时电池充电饱和、光伏仍保持 MPPT**  
   论文完整场景开始时接近空载，电池达到充电电流边界后仍有光伏剩余功率，母线会持续升高。新增的标准块子系统包括：

   - `PV_Curtail_Protection`：电压继电器、充电饱和资格判断、Unit Delay 锁存和逻辑门
   - `PV_Curtail_Duty_Controller`：常量、求和、比例增益和占空比限幅
   - `PV_Duty_Bumpless_Transfer`：Rate Limiter，用于限发与 MPPT 之间无扰切换

   没有新增 MATLAB Function 块。

7. **3.5 s Q–V 下垂故障和真实电压跌落缺失**  
   `GridVpu_profile` 外推曾把 0.9 pu 继续推到巨大负值，使 `Q_ref` 达到约 −90 Gvar，母线坍塌。保持最终值后，`Q_ref` 正确为 −0.4 Mvar。最终副本又使用以下官方块实现真实 10% 电源跌落并保留原电网阻抗：

   - Three-Phase Programmable Voltage Source
   - Three-Phase Series RLC Branch（RL 模式，0.8929 Ω / 16.58 mH）
   - Ground

## 参数扫描中淘汰的方案

以下方案经相同检查点对照后均未保留：

- 大幅降低并网 Vdc→P 外环带宽：辐照度爬坡时母线升至 1300 V 以上，恢复过慢
- 将 `Pref_max` 压到 1.1/1.4 MW：实际交流功率不足，母线出现持续高压
- 用实际 `Pf` 启用 PID tracking anti-windup：FCS 指令到实际功率不是单位增益，导致母线偏高
- 将 `lambda_mppc` 降为 0：80 Hz 左右的有界功率纹波没有实质变化

这些候选均已从最终模型撤回。

## 工程边界与解释

- 全局母线最小值 983.308 V，发生在 2.51232 s 的 1 MW 直流负载突加；43.04 ms 后恢复到 ±2% 带。
- 全局母线最大值 1361.554 V，发生在 0.02496 s 启动阶段；事件稳态窗口均回到 1200 V 附近。
- 电池功率范围约 −0.611 MW 至 +0.574 MW。模型按 `0.5 MW / 300 V` 限制电池电流，端电压偏离 300 V 时瞬时端口功率会超过 0.5 MW；若后续需要严格硬功率限幅，应增加基于实测 `Vbat` 的动态电流限值。
- 2.2–2.4 s 的 FCS 并网功率纹波有界，母线标准差约 8.7 V（0.73%），没有增长。
- SOC 在本次短时仿真中约为 54.254%–54.275%，变化很小，符合 4 s 时间尺度。
