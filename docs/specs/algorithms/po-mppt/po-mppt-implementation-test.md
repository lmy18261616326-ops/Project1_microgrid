# P&O MPPT 实现与验证规范（第二阶段）

## 1. 离散控制律

测量采用一拍延迟，因此控制器在第 `k` 拍使用上一采样时刻的对象量：

```text
V[k] = Vpv_meas[k-1]
I[k] = Ipv_meas[k-1]
P[k] = V[k] · I[k]
ΔP[k] = P[k] - P[k-1]
```

扰动方向 `s ∈ {-1,+1}`：

```text
若 ΔP[k] < -ΔP_threshold，则 s[k] = -s[k-1]
否则                           s[k] =  s[k-1]
```

占空比更新：

```text
Dcandidate[k] = D[k-1] + s[k] · ΔD
D[k] = sat(Dcandidate[k], Dmin, Dmax)
```

## 2. 参数

| 参数 | 值 | 说明 |
|---|---:|---|
| `MPPT_Ts` | `0.002 s` | MPPT 实际更新周期 |
| `MPPT_D_init` | `0.5656125` | 占空比初值 |
| `MPPT_D_step` | `0.0005` | 每拍扰动幅值 |
| `MPPT_D_min` | `0.05` | 占空比下限 |
| `MPPT_D_max` | `0.90` | 占空比上限 |
| `MPPT_dP_threshold` | `0.1 W` | 功率下降死区 |
| `MPPT_P_init` | `9591.75 W` | 前一拍功率初值 |

## 3. 关键实现决定

1. `Vpv_Sample_Hold` 和 `Ipv_Sample_Hold` 使用 `Unit Delay`，不是直接馈通的采样保持模块。
2. 功率差为“当前功率减前一拍功率”，`Sum` 的符号必须为 `+-`。
3. 比较阈值使用常数 `-MPPT_dP_threshold`，关系运算为 `<`。
4. `Switch` 的条件为 `u2 >= Threshold`，阈值 `0.5`；布尔真时选择反向后的方向。
5. `Duty_Limits` 输出同时反馈给 `Previous_Duty`，确保保存的是限幅后的真实命令。

## 4. 验证场景与判据

### 场景 A：额定环境、负载阶跃

- 温度：`25 °C`
- 辐照度：`1000 W/m²`
- 负载：`50 Ω`，在 `4 s` 变为 `25 Ω`
- 仿真时间：`8 s`

通过判据：

- 所有状态、功率和占空比均为有限值。
- 占空比始终位于 `[0.05, 0.90]`。
- 稳态光伏功率接近 `9.60 kW`。
- 模型无未连接端口、悬空连线和 Stateflow 编辑期错误。

### 已验证基线

- 阶跃前平均光伏功率：`9603.75 W`
- 最终平均光伏功率：`9603.78 W`
- 最终平均直流母线电压：`597.18 V`
- 全程占空比范围：`[0.5471125, 0.5666125]`

直流母线最终值与 `600 V` 存在偏差是预期现象，因为电池侧占空比仍为开环常数。
